## 1. `scanf.c`（严重误导新手的运行时逻辑 Bug）

- **问题等级**：🔴 高（功能错误 / 严重误导初学者）
- **问题位置**：第 28 行
- **原代码**：
  ```c
  int n = 0;
  printf("Enter a number: ");
  scanf("%d", &n);
  printf("n: %d\n", &n);
  ```
- **编译器表现**：`gcc -Wall` 发出警告 `format '%d' expects argument of type 'int', but argument 2 has type 'int *'`。
- **问题分析**：`printf` 中误把变量地址 `&n` 当成变量值 `n` 打印，零基础初学者运行后看到的不是自己输入的数字，而是一个被截断的栈内存地址值（乱码一样的数字）。
- **修改建议**：
  ```c
  printf("n: %d\n", n);
  ```
  同时建议检查 `scanf` 的返回值是否为 `1`（或补充注释说明），避免非法输入时使用未更新的变量值。
